## 2. The decisive correction: A1's Priority-1 target is already proved — and already barred

A1 allocates **70% of effort** to proving the "signed energy theorem"

```
sum_r |R_chi(r)|^2 <<_eps D^2 X^eps,   R_chi(r) = sum_{x+y=r} A_chi(x) A_chi(y),
```

with the signed lift bound `|A_chi(p/q)| << q/(D|p|)` as input. The graph disposes of this completely:

- `M9-M2-signed-lift-cancellation-B1` (`proved_internal`, blind-rederived and adversarially reviewed in the `m9-signed-lift-capacity` campaign): A1's lift bound, **with scope conditions the memo omits** — even `p` gives `A_chi = 0`; the odd-`p` bound requires a uniformly bounded `chi_4`-twisted discrepancy / scale-normalized BV profile ("boundedness or unnormalized smoothness alone is insufficient"); and it is "an individual pair-weight lemma only."
- `M9-M2-B1-energy-capacity-barrier` (`proved_internal`): assuming B1, the divisor identity **already gives** `sum_r |R_chi(r)|^2 <<_eps D^2 X^eps` — A1's target theorem is a proved consequence, not an open problem. The same node proves the route obstruction: rational spacing then yields only the smoothed global capacity `D^2 X^eps (1 + D^4/X)`, and an exact-support envelope model has normalized critical fat-band mass `>> D^3/X`, so **B1 plus this energy cannot yield `|c_chi| << X^eps` for `D >= X^(1/3+δ)`**. The barrier is scoped correctly: it does not refute the actual `chi_4` lift system; it refutes the sufficiency of exactly the argument A1's Priority 1 proposes.
- `M9-M2-signed-fat-band-constant` (`proposed`, unchanged): A1's Route-A object `c_chi^V(D;X)` verbatim, parked behind the open blocker `M9-M2-fourth-moment-average-to-pointwise`, with the capacity report attached as negative evidence against "B1 alone implies the constant."

So Route B is not a new route; it is the early-round ancestor of the current program. Its genuinely open content — sign-preserving cancellation across distinct rational rays with the actual coefficients — was carried forward through the R75–77 gcd-lift normal form and is now frozen, in strictly sharper form, as the 80.G cross-row `chi_4(h)chi_4(s)` density–discrepancy energy. Any Route-B-style proposal must enter through the 80.G interface and must cite `M9-M2-B1-energy-capacity-barrier` as its named false analogue. Adopting A1's 70% allocation as written would spend the program's main effort proving a proved statement that a proved barrier says cannot close the range that matters.
