## R3. Coefficient-blindness tagging rule (new)

Every obligation node receives a metadata tag `cb: true` or `cb: false`.

- `cb:true` — the statement is true (or targeted) uniformly over bounded coefficients: counting statements, spacing counts, moment estimates over an X- or t-window, incidence bounds. Decoupling (including small-cap), large sieve, exponent pairs, and generic Diophantine counting are lawful here.
- `cb:false` — the statement fails for adversarial coefficients of the same magnitude (C3): the signed pointwise bridge, the transposed-row energy, the signed resonant-union bound. Coefficient-uniform theorems may appear inside as counting inputs but never as the closing step; the closing step must cite the exact `chi_4`/`Phi`/profile property used.

The tag makes rule R2.4 mechanical and prevents the recurring import-audit failure mode (23 failed imports to date, all on `cb:false` targets).

### R4.3 Round 78 — reciprocal-resonance inverse theorem (`proposed`)

Decompose the resonant set

```
Res = { (a,b,k) : || Lambda_{a,b}/k || <~ G_{a,b}^(-1) }  =  Res_structured ⊔ Res_generic
```

and run three orthogonal tasks.

**(a) Square-family adjudication — the first decidable sub-question.** On `a = s^2`, `b = t^2`, `s,t` odd coprime, `t - s = 2u`: `(sqrt b - sqrt a)^2 = 4u^2`, so the criterion degenerates to `|| 2u^2 X / k || <~ G^(-1)` — a divisor-structured `k`-set plus a metric set. Two exact facts (A2, verified):
  - sign inertness: `q = (t^2 - s^2)/2 = 2u(s+u)` is even on **every** odd-square ray, so `(-1)^q = +1` identically — the offset-character mechanism supplies no cancellation anywhere on the square family;
  - half-integer coherence: at `alpha in Z + 1/2`, `e(g alpha) = (-1)^g = -1` for all odd `g` — full in-ray coherence (this is the R76 parity theorem specialized).
  Task: prove or refute that the total beta-weighted square-family resonant mass is `<<_eps L^2 X^eps` uniformly in `X`, treating the divisor `k`-set exactly and the metric `k`-set by counting; accompany with a finite diagnostic (within the 20% cap) charting mass against `L` for adversarial `X = T^4` families. Outcome semantics: pass → the survivor stands its most structured stress test and the enemy is `Res_generic`; fail → the survivor inequality is false as stated and the route forks now (collar/mod-4 repair, or an exceptional-X reformulation of M9), before further rounds are spent.
**(b) Generic incidence bound.** For `Res_generic` (squarefree kernel of `ab` nontrivial), prove a determinant/incidence/additive-energy bound for pair-coincidences `|| Lambda_{a,b}/k - Lambda_{a',b'}/k' || <= eta`. Method guidance: Robert–Sargos' lesson (Crelle 2006) — replace an unavailable spacing lemma by a four-variable Diophantine count; Kiyohara (arXiv:2205.08206) — measure minimal separation and the doubling constant of the actual frequency set before invoking any decoupling. High multiplicity must force structure: common squarefree kernels, `a = u^2, b = v^2`, low-rank relations among `(u, v, k)`, small doubling in a suitable parameterization.
**(c) Hostile lower-bound construction.** Attempt to construct an actual-coefficient-weighted configuration violating the target. The required output of Round 78 is a power-saving theorem or a rigorous no-go showing the absolute resonance capacity is too large — either is promotable.

`(81,121)` is a standing control model for all three tasks.
