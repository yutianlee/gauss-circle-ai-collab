1. The (q=8) residual has full directed degree; a proof based only on local
   sparsity is false.
2. The complete descent and inverse transform are exactly invertible; a
   second completion gives no power by itself.
3. Arbitrary bounded coefficients can phase-conjugate a proposed matrix and
   saturate Schur capacity. A successful argument must name the actual-symbol

4. Absolute values before the conductor, shift, or four-row sums destroy the
   required power.
5. Perfect-square, fourth-power, prime-power, and modulus-multiple phase
   families must be counted at the actual coefficient scale.
6. A local square-root complete-sum estimate is insufficient if summing its
   absolute values recreates (J^{1/6}).

## 5. Quantitative exit rules

The round succeeds analytically only if it gives one of:

- the full boxed estimate;
- an exact nonempty hard subrange with a strict saved power and a disjoint
  residual owner;
- a rigorous no-go showing that the proposed high-trace/spectral mechanism
  has an actual coherent eigenspace or an exact equal-capacity return.

A qualitative analogy, a generic trace-function statement, or a theorem with
separable coefficients is not enough.
