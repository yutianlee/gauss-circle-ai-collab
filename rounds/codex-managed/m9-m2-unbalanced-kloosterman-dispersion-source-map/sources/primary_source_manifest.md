Only primary sources may support imported mathematical claims.

1. Sandro Bettin and Vorrapan Chandee, *Trilinear forms with Kloosterman fractions*, arXiv:1502.00769v1, submitted 3 February 2015; published in *Advances in Mathematics* 328 (2018), 1234--1262.
   - Abstract and version record: https://arxiv.org/abs/1502.00769
   - Primary HTML text: https://arxiv.org/html/1502.00769v1
   - Audit Theorem 1, Remark 1, Theorem 2 only if relevant, and Corollary 1 only if an exact determinant dictionary is proposed.

2. Thomas Wright, *Trilinear Kloosterman fractions I: partially fixed moduli and unbalanced convolutions*, arXiv:2604.25177v2, revised 7 August 2026.
   - Abstract and version record: https://arxiv.org/abs/2604.25177
   - Primary HTML text: https://arxiv.org/html/2604.25177v2
   - Audit Theorem 2.1 as the fixed-denominator-factor estimate. Audit Corollary 2.2 or Theorem 2.3 only if a literal fixed-residue dispersion dictionary is first derived.

3. Negative bibliographic control: arXiv:2601.00292v2, *Bilinear forms with Kloosterman fractions and applications*, is withdrawn and explicitly records a missing factor in its claimed improvement. It may not be used as a theorem.
   - Withdrawal record: https://arxiv.org/abs/2601.00292

For every source claim record the precise version, theorem number, notation, support, coprimality, coefficient norm, phase convention, fixed-factor hypothesis, absolute-value placement, parameter range, and whether the constant is uniform in the parameter being mapped.
