# Round 101 conductor owner and capacity review

## One-count owners

The nonempty two-adic mask is all odd residues; it is never a partially
populated local orbit. Ownership is imposed only after reconstructing the
full physical ordered pairs and the odd cofactor.

- The integer \(u=0\) is owned once. A nonzero global integer with local
  residue zero remains.
- A fully aligned pair has local return
  \(L/\gcd(L,v)\), and the full return also includes the odd translation
  order. Only return \(1\) belongs to Round 87, and only returns at most
  \(\rho_*\) belong to the Round-88 coarse package.
- The Round-100 aligned \(q=8\) slice has return \(4\), so its prior
  ownership remains correct. Higher two-parts with odd \(v\) can have
  return \(L>\rho_*\), so blanket aligned deletion is false.
- Exact reversal is a distinct ordered edge. On the fully aligned local
  reversal its shift is \(v-a\); its convolution is Hankel-type, not a
  positive square. It is deleted only after its own full return test.
- A lower reciprocal period is Round-89-owned only if the complete cell or
  summable union meets the accepted directed-degree threshold. Period
  alone is not an owner.

These tests give a disjoint successive complement and leave the scalar
\(\mathscr S_{2\text{-adic}}(U)\) exactly once.

## Capacity verdict

The normalized local matrix is unitary. If the reciprocal factor has
period \(P\) and \(d=L/P\), the Fourier support lies in one affine class
modulo \(d\); the factor \(d/L=1/P\) in the descended transform gives
unitary \(P\)-blocks and an affine permutation of residue blocks. Hence
period depth gives exact self-return, not a rank or norm gain.

For arbitrary coefficients one can take \(G_{j-v}=w_jF_j\) and saturate

\[
 |\mathcal C_{2^\nu}(F,G)|=\|F\|_2\|G\|_2.
\]

This falsifies every coefficient-blind \(2^{-\delta\nu}\),
\(L^{-\delta}\), or \(J^{-1/6}\) deduction. It is not a lower bound for the
literal actual rows. The only unexcluded route is cancellation in the full
fixed-vector scalar after the odd labels and conductor rows are summed
before absolute value.

## Decision

Promote the exact normal form, twisted-period routing, full-rank unitarity,
and qualified owner map. Retain the fixed actual-vector estimate and every
downstream theorem open. Reject low rank, period-sparsity saving, blanket
aligned ownership, blanket reversal ownership, and treating the mod-\(8\)
quotient as the higher two-part.
