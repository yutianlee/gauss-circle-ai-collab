This candidate is a local reproduction for Round 98. It proves only
bookkeeping and conditional implications. No open signed estimate is assumed.

   \(\ell=\delta-1/4\);
4. the full second-derivative theorem at \((\delta,\ell)=(1/2,0)\);

\[
 \mathcal U_1=
 \{(\delta,\ell)\in\Omega:
 \ell<\delta-1/4,\ 178\ell+1638\delta>463\}
 \setminus\{(1/2,0)\}.
\]

Physical hard/smooth ownership is then imposed on the literal profile label,
not inferred from \(\delta\). On the unique hard label the open owner is the

\[
 \boxed{

This is a proved conditional reduction, not an estimate of either open

## 2. Scope of the canonical Gram

The canonical Gram belongs to the product-wavelet/Farey-conductor analysis
of one transition-flattened smooth nonaxial principal component in

\[
 J^{13/18}<C_{\rm cond}\leq J^{3/4}.
\]

Even if its boxed estimate is granted, it supplies neither the hard physical
top cone nor a uniform estimate for every smooth physical
\((D,L)\in\mathcal U_1\). The global angular recombination used before the
product-wavelet analysis has already summed the denominator and frequency
partitions, so no inverse logical implication to an individual block exists.
Thus the canonical theorem is not a direct parent of blockwise `M9-M1`.

Within its own transformed route it still leaves upper conductors
\(C_{\rm cond}>J^{3/4}\), axes, raw transitions, cone edges, other radial
sectors, and alpha/top interfaces. This is a strict route-scope obstruction,
not a counterexample to the canonical estimate.

## 3. Global radial physical owner tree

\[
 \mathcal G_X=
 \Re\left\{e(1/8)\sum_{n\leq16\sqrt X}
 \mathcal C_X^*(n)n^{-3/4}e(\sqrt{Xn})\right\}.
\]

Use a smooth radial partition before choosing any Mellin, product-wavelet, or
conductor attack. There are three physical owners:

1. fixed critical sectors \(n\asymp\sqrt X\), compactly supported in
   \((0,16\sqrt X)\), already proved by terminal transfer;
2. the exact lower-radial aggregate \(0<n/\sqrt X\to0\), still open;
3. the sharp upper radial endpoint and partition interfaces, still open.

\[
 \boxed{

The implication is a one-count radial assembly. It is independent of the
direct blockwise assembly.

## 4. Alternative analytic decompositions

owners, not simultaneous physical summands:

- the one-sided-divisor/Appell and reciprocal-product-wavelet route;
- low-, first-, and upper-conductor Farey decompositions;

alternative ways to attack overlapping unresolved material. The hard top

\[

 \Longrightarrow \mathrm{GC\ target}.}
