# Round 160 barrier packet: M2 UNBAL inverse-selector reciprocity

## Frozen owner

This campaign treats one flat-smooth strict-UNBAL M2 component only.  Put

\[
 X=N_0+\xi,\quad D=X^\delta,\quad L=X^\ell,\quad
 R=X/D,\quad K=XL/D^2,\quad \Delta=D/L,
\]

with

\[
 \frac14\le\delta<\frac12,\qquad
 0\le\ell<\delta-\frac14,\qquad
 178\ell+1638\delta>463.
\]

The exact centered nonzero-frequency survivor is

\[
 \mathscr R^\circ_{D,L}(X)=
 \sum_{\substack{g,n\ \mathrm{odd}\\gn\asymp R}}
 \chi_4(g)W\!\left(\frac{X}{gnD}\right)
 \sum_{1\le h<n}\widehat\gamma_{g,n}(h)
 S^{\chi_4}_{\infty0}(4N_0,h;2n),
\tag{160.B1}
\]

with target (O_\varepsilon(X^{1/4+\varepsilon})).  The (h=0) class is
already target-safe and is removed exactly once.

## Literal coefficient

For (r=gn), (k=gj), and ((j,n)=1), retain

\[
 b_{g,n}(j)=\frac{q_L(4Xj/(gn^2))}{gj}e(\xi j/n),
\]

the moving \(j\)-support \(\mathcal J_{g,n}\), all profiles, entries, exits,
real-centre factors, and zero extension.  Define

\[
 \widehat\gamma_{g,n}(h)=\frac1n
 \sum_{\substack{j\in\mathcal J_{g,n}\\(j,n)=1}}
 b_{g,n}(j)e(-h\overline j_n/n).
\tag{160.B2}
\]

The only new algebraic insertion is

\[
 e(-h\overline j_n/n)
 =e(h\overline n_j/j-h/(jn)).
\tag{160.B3}
\]

It must be applied before every positive modulus norm.

\[
 \beta(a)=\min(a,(1-a)/2).
\]

\[

modulus, fixed-(h) cancellation, outer-(g) cancellation without (g=1),
positive modulus norms, full-frequency inversion, residue classes without
their count, or an external theorem without exact hypotheses.  Do not
transfer a flat-packet result to any nonflat or downstream owner.
