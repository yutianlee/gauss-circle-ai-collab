### 2.2 Mili\'cevi\'c--Robinson--Shupe

The current official record is Mili\'cevi\'c--Robinson--Shupe,
[arXiv:2608.21346v1](https://arxiv.org/abs/2608.21346), submitted
2026-08-21 17:53:46 UTC.  The
[v1 theorem text](https://arxiv.org/html/2608.21346v1) defines, for an odd
prime \(p\) and \(q=p^n\), normalized \(\operatorname{Kl}_2(a;q)\) and the
complete shifted product

\[
 S(\boldsymbol a;q)=
 \sum_{\substack{x\bmod q\\(x+a_i,q)=1\ \forall i}}
 \prod_{i=1}^k\operatorname{Kl}_2(x+a_i;q).
\]

With \(\Delta^*(\boldsymbol a)\) exactly as in Definition 2, Theorem 1.1 is

\[
 S(\boldsymbol a;p^n)
 \ll_k
 p^{\,n-(n-\Delta^*(\boldsymbol a)-1)/\lceil k/2\rceil+1}.
\]

It is pointwise in a fixed shift tuple, complete in one residue variable,
and supported at one odd prime-power modulus.  It is not a theorem for
arbitrary coefficient sequences or for a signed family retained beneath one
outer real part.  For generic alignment \(\Delta^*=0\), putting
\(r=\lceil k/2\rceil\) gives exactly

\[
 |S(\boldsymbol a;q)|\ll_k q^{1-1/r}p^{1+1/r}.
\]

For deep alignment \(\Delta^*=n\), the stated bound permits full size
\(q\), consistently with Example 1.  For \(k=2\), Remark 4 identifies a
Ramanujan sum and the stated depth-\(n-1\) vanishing threshold.  Proposition
5.3 admits only its scale-invariant bounded weights; it does not supply an
arbitrary incomplete Archimedean weight.

The report gives the correct first failed hypotheses:

- **K17a:** the project object is a centered Ramanujan/projector defect with
  lifted physical selectors, endpoints, orientation and alias signs, over
  arbitrary odd reduced conductors—not a fixed generically aligned tuple in
  a complete \(p^n\)-sum.
- **K26:** the unequal-product object is an Archimedean Gram row with
  nonzero product gaps, sinc/chirp/square-root phases, literal selectors,
  and hard cell endpoints; it has no complete residue variable or fixed
  prime-power modulus.
- **(K185.37):** the variables are primitive integer fields, affine row
  positions, and a varying height, with two orientations and one final real
  part; there is no Kloosterman-product modulus to which Theorem 1.1 applies.
- **UNBAL:** a scalar complete sum at one fixed modulus cannot replace the
  signed varying-modulus literal matrix vector required before norms or
  absolute values.

The report also keeps fictional powers honest.  A hypothetical generic
