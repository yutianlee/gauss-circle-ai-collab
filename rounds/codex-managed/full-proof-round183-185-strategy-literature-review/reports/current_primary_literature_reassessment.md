### 2.2 Mandatory new candidate: Mili\'cevi\'c--Robinson--Shupe

The current source is
[arXiv:2608.21346v1](https://arxiv.org/abs/2608.21346), submitted
2026-08-21 17:53:46 UTC; the theorem text was checked in the
[v1 primary HTML](https://arxiv.org/html/2608.21346v1).

For an odd prime \(p\), \(q=p^n\), the paper normalizes

\[
 \operatorname{Kl}_2(a;q)=q^{-1/2}
 \sum_{x\bmod q}^{*}e\!\left({x+a\bar x\over q}\right).
\]

For a fixed integer \(k\geq1\) and shift tuple
\(\boldsymbol a=(a_1,\ldots,a_k)\in(\mathbb Z/p^n\mathbb Z)^k\), it studies
the **complete** sum

\[
 S(\boldsymbol a;q)=
 \sum_{\substack{x\bmod q\\(x+a_i,q)=1\ \forall i}}
 \prod_{i=1}^{k}\operatorname{Kl}_2(x+a_i;q).
\]

Theorem 1.1 states, with the paper's alignment depth
\(0\leq\Delta^*(\boldsymbol a)\leq n\) from Definition 2, as follows.  Let
\(T\) be the set of residues modulo \(p\) attained by the shifts and write
the shift multiset as the disjoint union
\([a_1,\ldots,a_k]=\bigsqcup_{t\in T}[a_{t1},\ldots,a_{tk_t}]\), with
\(a_{ti}\equiv t\pmod p\).  For two equal-length tuples set

\[
 \Delta(\boldsymbol a,\boldsymbol b)
 =\min_{1\leq j\leq \ell}
   \operatorname{ord}_p\gcd\!\left(p^n,
       \sum_{i=1}^{\ell}(b_i^j-a_i^j)\right).
\]

Then

\[
 \Delta_t(\boldsymbol a)=
 \max_{\substack{[k_t]=I\sqcup I'\\|I|=|I'|=k_t/2}}
 \Delta(\boldsymbol a_t^I,\boldsymbol a_t^{I'}),
 \qquad
 \Delta^*(\boldsymbol a)=\min_{t\in T}\Delta_t(\boldsymbol a),
\]

with \(\Delta_t=0\) when \(k_t\) is odd.  Thus
\(\Delta^*(\boldsymbol a)=0\) unless the shifts can be paired modulo \(p\).
With that exact definition,

\[
 S(\boldsymbol a;p^n)
 \ll_k p^{\,n-(n-\Delta^*(\boldsymbol a)-1)/\lceil k/2\rceil+1}.
 \tag{MRS-1.1}
\]

The quantifier is pointwise in the fixed shift tuple, not an average over
shift tuples.  The variable \(x\) runs through the full residue ring modulo a
single odd prime power.  There are no arbitrary coefficient sequences and no
outer signed family before an absolute value.  For generic alignment
\(\Delta^*=0\), writing \(r=\lceil k/2\rceil\), the theorem is

\[
 |S(\boldsymbol a;q)|\ll_k q^{1-1/r}p^{1+1/r}.
 \tag{MRS-generic}
\]

Deeply aligned tuples need not enjoy this saving: at
\(\Delta^*=n\), the displayed estimate allows full order \(q\), and the
paper's Example 1 exhibits full-size behavior.  For \(k=2\), Remark 4
identifies the complete correlation with the Ramanujan sum
\(c_q(a_1-a_2)\), which vanishes unless the shifts are aligned to depth at
least \(n-1\).  Proposition 5.3 permits certain bounded weights invariant at
the paper's \(p^{\kappa_0(F)}\) scale; it does not convert the theorem into an
arbitrary incomplete or Archimedean weighted estimate.

The first failed interfaces are therefore:

- **K17a:** K17a's \(\mathcal K_q^\circ\) is a centered
  Ramanujan/projector object coupled to lifted physical selectors, endpoint
  profiles, orientation and alias signs over arbitrary odd reduced
  conductors.  It is not \(S(\boldsymbol a;p^n)\), and K17a does not provide
  a fixed, generically aligned shift tuple to which (MRS-1.1) applies.
- **K26:** the unequal-product row is an Archimedean Gram sum with nonzero
  product gaps, sinc/chirp and square-root phases, hard cell endpoints, and
  literal selector coefficients.  It has no fixed modulus \(p^n\), complete
  residue variable \(x\), or fixed product of \(\operatorname{Kl}_2\)'s.
- **(K185.37):** the summation is over primitive integer fields and affine
  row positions, with a varying height \(h\), two orientations, zero
  extensions and one global real part.  There is no modulus or Kloosterman
  product.  The failure occurs before any parameter or power comparison.
- **UNBAL:** a complete scalar sum at one fixed prime-power modulus does not
  supply the varying-modulus signed vector estimate required before norms.

## 3. Proof or derivation

### 3.1 Audit method

For each source, the check was performed in this order:

1. identify the current primary record and exact version at the cutoff;
2. read the theorem, definitions it invokes, and any exceptional or
   degeneracy clause;
3. record whether the theorem is pointwise or averaged, complete or
   incomplete, fixed-modulus or varying-modulus, and where absolute values
   or positive norms occur;
4. compare the theorem's admissible coefficient/test-function class with the
   literal project coefficient before changing variables;
5. only if the interface survived, restore all project multiplicities and
   powers; and
6. stop at the first failed hypothesis.  Purely fictional scale comparisons
   are labelled diagnostics, never imports.

This order is essential.  A numerical saving from a complete finite-field
model does not prove an Archimedean literal-row theorem, and a moment estimate
with an absolute value inside a family average cannot be moved outside that
average without a new argument.

### 3.2 Mili\'cevi\'c--Robinson--Shupe restored powers

Let \(r=\lceil k/2\rceil\).  From (MRS-1.1) with
\(\Delta^*(\boldsymbol a)=0\),

\[
 p^{n-(n-1)/r+1}
 =p^{n(1-1/r)+1+1/r}
 =q^{1-1/r}p^{1+1/r}.
\]

Hence the relative complete-sum saving is
\(q^{-1/r}p^{1+1/r}\), not a uniform pure power of \(q\).  Two diagnostics
show both the attraction and the limitation of the theorem.

**K17a diagnostic.**  K17a's positive high-conductor scale is
\(Lq\log(2q)\); suppress the harmless logarithm for the power comparison.
For \(k=2\), \(r=1\), the generic displayed bound is \(O(p^2)\).  A wholly
unsupported replacement of K17a's conductor block by this complete
correlation would therefore restore

\[
 Lq\cdot{p^2\over q}=Lp^2.
\]

This is target-like only when \(p=X^{o(1)}\), but the project provides no
prime-power reduction, fixed two-shift tuple, generic alignment, or complete
residue realization.  Moreover, the actual \(k=2\) identity is a Ramanujan
sum and the theorem's cancellation depends on shift alignment; it is not a
black-box full-\(q\) saving for arbitrary K17a data.  The first failure is
therefore the kernel/conductor map, not the residual \(p^2\).

For \(k=4\), \(r=2\), the generic bound is
\(q^{1/2}p^{3/2}\); restoring against \(Lq\) gives

\[
 Lq^{1/2}p^{3/2},
\]

still larger than \(L\) for an unbounded conductor.  Thus even the fictional
power map would not close K17a.

**K26 diagnostic.**  K26 is missing a factor \(L\) from capacity \(L^2\)
to local target \(L\).  If one fictionally set \(q\asymp L^2\), a generic
\(k=4\) complete correlation would replace \(q\) by

fixed shifts, no alignment-depth control, and no product-of-Kloosterman
representation.  It also has literal hard endpoints and a jointly varying
coefficient.  The formal exponent resemblance therefore carries no state

modulus; \(t\) lies on an oriented affine positivity interval, not a complete
residue system; and \(B^\sigma_{\mathfrak f,\omega}(t)\) is not a product of

separately to fields or heights would yield a positive recombination.  The
number of height blocks is already reflected in the capacity
\(O_{B,\varepsilon}(YL^2X^\varepsilon)\), so that procedure cannot manufacture the needed
global factor \(Y\).
