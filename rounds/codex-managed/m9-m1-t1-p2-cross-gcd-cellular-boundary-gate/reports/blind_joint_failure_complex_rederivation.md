## 3. Proof and derivation

### 3.1 Exact complete lower edge

Put

\[
 v_0=(g\alpha,m,g\beta,m'),\qquad
 v_1=\tau _0v_0=(gm,\alpha,g\beta,m').
\tag{3.1}
\]

\[
 (gm,g\beta)=g(m,\beta)=g.
\tag{3.2}
\]

Applying the same complete allocation map at \(v_1\) returns \(v_0\).
The lower \(P_2\) expression is merely reversed,

\[
 |g\alpha-gm|=|gm-g\alpha|,
\]

and the upper expression is unchanged. Moreover
\((\alpha,\beta)=1\), the character label remains
\(\chi _4(m\alpha)=-1\), and the two sharp codes are exchanged. Therefore
\(P_{\partial\rm lit}\) is invariant under \(\tau _0\).

Let \(C_i=\chi _4(d_i)\chi _4(d'_i)\). On the oriented edge
\(e=[v_0,v_1]\), the actual character transport is

\[
 q_e=\frac{C_1}{C_0}
 =\frac{\chi _4(gm)}{\chi _4(g\alpha)}
 =\chi _4(\alpha m)=-1.
\tag{3.3}
\]

With the convention

\[
 \partial_\chi e=[v_1]-q_e[v_0],
\tag{3.4}
\]

both physical corners occur with coefficient \(+1\). There is no fixed
point in this sector because \(\chi _4(\alpha^2)\ne-1\). Orient each

\[
 U(v_0)=\chi _4(g\beta)\chi _4(g\alpha)
 \Phi_{r,\sigma}(N)\lambda_{N+r,\sigma}(g\beta).
\tag{3.5}
\]

Evaluation of (3.4) with the actual endpoint products gives exactly

\[
 W(v_0)+W(v_1)
 =U(v_0)\,
 \overline{\lambda_{N,\sigma}(g\alpha)
           -\lambda_{N,\sigma}(gm)}.
\tag{3.6}
\]

Let \(\mathbf e_{\mathfrak c}\) be the basis vector of the free module on
all sharp codes, including \(\dagger\). The complete weighted sharp-code

\[
 \mathbf J_{\rm lit}(e)=U(v_0)\left(

\tag{3.7}

Augmenting each code basis vector to \(1\) recovers (3.6). Formula (3.7)
retains the unequal numerical endpoints and any \(\dagger\) corner.
