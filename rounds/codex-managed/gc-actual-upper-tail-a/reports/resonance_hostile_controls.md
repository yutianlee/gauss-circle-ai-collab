## 1. Result: exact arithmetic classification and a scoped no-go

Three conclusions are proved.

1. The actual character products attached to two reciprocal frequencies have an exact gcd and 2-adic classification. In the equal-valuation case their sign is constant on every fixed product-difference class. In particular, coincident products can give positive covariance of the same size as the individual energies; oddness at exact resonance does not suppress this covariance.
2. This is realized with the actual positive smooth divisor amplitude from the frozen full band, at norm scale `N=T^(2/3)`. For two distinct reciprocal frequencies, localized real resonance contributions can satisfy

       integral G_h G_h' dmu_T asymp N^(-1/2),
       integral G_h^2 dmu_T asymp integral G_h'^2 dmu_T asymp N^(-1/2).

   Thus a uniform power-saving decorrelation claim for every distinct pair of reciprocal frequencies is false. There are equally explicit negative-covariance and disjoint-support controls. These are real, many-radius controls with the actual character and an actual smooth summand of the divisor decomposition. They are not lower bounds for the full band or its upper tail.
3. Each integer product center contributes at most `T^(-1/2+epsilon)` to one actual rectangle. Consequently an event at height `V>=T^(16/125)` cannot be generated by one divisor packet, or by only `T^o(1)` product centers. After a negligible controlled far-product truncation, it requires at least `V T^(1/2-epsilon)` centers with the sign of the resulting sum. At the threshold this is `T^(157/250-epsilon)`. The unresolved problem concerns the signed aggregate of this growing number of distinct centers.

No estimate A or complete moment improvement is proved. The report rejects only a proposed uniform pairwise-decorrelation certificate and any argument that deletes coincident-product covariances solely because the individual kernel is odd. It does not reject aggregate cancellation, an exceptional-set argument, target A, or the complete `32/25` moment bound.

## 2. Exact statement and hypotheses

Use the frozen actual full band `F`, with `gamma=16/125`, `X=T^(64/125)`, `Y=T^(93/125)`, the fixed `rho,Psi,eta,w`, and unnormalized measure `dmu_T=w(R/T)dR`. The actual divisor identity is `r2(n)=4 sum_(d|n) chi4(d)`.

For a smooth rectangle `DM asymp N` from the divisor expansion, let `a(d,m)` be its real smooth amplitude, with fixed support ratios and

    |partial_d^j partial_m^k a(d,m)| << N^(-3/4) D^(-j) M^(-k).

For `R asymp T`, the inherited, corrected stationary main term is

    S(R)=-Re sum_(h asymp H) sum_d chi4(d)b_h(d;R)e(R^2 d/(4h)),
    H asymp TD/sqrt(N),
    b_h(d;R)=a(d,R^2d/(4h^2)) R sqrt(d)/(sqrt(2)h^(3/2)).       (2.1)

The factor 4 may be included in `a`. All constants below allow that harmless choice. The positive branch and original circle shift are as in the frozen interface; the other branch is its conjugate, not an independent summand to cancel.

Put `x=R^2`. For each positive integer h select the unique positive odd integer `q_h(x)` such that

    h(q_h-1) <= x < h(q_h+1),                              (2.2)

on the present range, where `x/h` is large. Ties go to the cell starting at that boundary. Set `p_h=h q_h` and `Delta_h=x-p_h`. Then the exact real fibre identity is

    S_h(R)=chi4(q_h) sum_(d odd)b_h(d;R)
                       sin(pi Delta_h d/(2h)).             (2.3)

This uses exactly one q per h. Switching from q to q+2 multiplies both the character and the odd-d sine by -1, so the value at a cell boundary has no artificial jump. Formula (2.2), including its half-open convention, is used throughout.

For the covariance control, let `tau` be an even nonnegative smooth cutoff supported on `[-c2,c2]`, equal 1 when `c1<=|u|<=c2/2`, where `c1=1/400`, `c2=1/100`. Define the localized actual contribution

    G_h(R)=tau(Delta_h/W) S_h(R),  W=T/sqrt(N).             (2.4)

This is a localization of an actual stationary contribution. It is not identified with F, and no estimate for F is transferred to this radius-dependent localization.

The arithmetic classification applies without amplitude hypotheses: for positive h,h', positive odd q,q', put

    g=gcd(h,h'), a=h/g, b=h'/g, r=hq-h'q', c=r/g.

When a,b are odd, necessarily c is even and

    chi4(q)chi4(q')=chi4(ab)(-1)^(c/2).                   (2.5)

When exactly one of a,b is even, c is odd. Along the admissible odd solutions to `a q-b q'=c`, the character product alternates when `(q,q')` advances by `(2b,2a)`. These alternatives exhaust the coprime pair a,b. In particular, `r=0` is possible with odd q,q' if and only if a,b are odd; then

    q=bk, q'=ak, k odd, chi4(q)chi4(q')=chi4(ab).         (2.6)

Equality of the 2-adic valuations of h and h' is equivalent to a,b both odd.

## 3. Proof and derivation

### 3.1 Product differences retain rigid character correlations

The identity `a q-b q'=c` proves the parity assertions. If a,b are odd, both `a q` and `b q'` are odd. For any odd v and even c,

    chi4(v+c)=(-1)^(c/2)chi4(v).

Apply this with `v=b q'`, use multiplicativity on odd integers, and multiply by `chi4(a)chi4(q')`. This proves (2.5) exactly, including negative r. Thus for fixed h,h',r in this case there is no residual character oscillation among the solutions q,q'. Any cancellation must occur between different r classes or come from the actual amplitudes and radius kernels.

For opposite parity a,b, all integer solutions differ by `(b t,a t)`. Maintaining q,q' odd requires t even. Advancing t by 2 changes each character by `(-1)^b` and `(-1)^a`, respectively, so the product changes by `(-1)^(a+b)=-1`. This is an available arithmetic oscillation, but using it analytically still requires control of the weights and the sharp solution range. It does not apply to the equal-valuation subfamily.

At r=0, coprimality forces `q=bk,q'=ak`. Both are odd exactly when a,b,k are odd, giving (2.6). For example the reduced pairs `(a,b)=(5,9)` and `(5,7)` give positive and negative covariance signs, respectively. The signs are fixed for every admissible k, although the two individual characters can both alternate with k.

### 3.2 An actual many-radius covariance control

Let g tend to infinity through positive integers and take

    T=15g, N=T^(2/3), D=M=T^(1/3).

Choose fixed nonnegative smooth functions omega and nu with `0<=omega,nu<=1`: omega is supported in `[1,1.1]` and positive on `[1.02,1.08]`; nu is supported in `[0.5,3]` and positive on `[0.6,2.6]`. Use the actual summand

    a_T(d,m)=4 omega(d/D)nu(m/D)phi(dm)(dm)^(-3/4)
                         Psi(sqrt(dm/T)).                (3.1)

This is obtained by inserting nonnegative smooth factor cutoffs in the exact actual divisor expansion; the complementary smooth amplitudes retain the remainder. No character is selected or changed. Since `dm asymp N`, the exponent inequalities `64/125<2/3<93/125` imply `phi(dm)=1` on this support for all sufficiently large T. Since `N/T -> 0` and `Psi(0)=1`, Psi is uniformly positive there. Hence a and all stationary b_h are nonnegative. This positivity follows from the actual fixed mollifier; it is not an assumption of arbitrary positive Fourier coefficients on the entire infinite series.

Take `h=5g` and `h'=9g`. On a fixed small interval around `R=T`, both stationary lines lie in the positive interior of (3.1): their m/d ratios at R=T are `9/4` and `25/36`. On a fixed interior d interval of length comparable to D, therefore,

    b_h(d;R) asymp b_h'(d;R) asymp T^(-1/2)D^(-1).      (3.2)

Their exact common product centers are

    p=45g k, k positive odd.

In an R interval of fixed positive length proportional to T around T there are comparable to T such centers. This count follows directly from an interval for p of length comparable to `T^2`, with spacing `90g asymp T`; no density theorem is used. The w window equals 1 there. Losing a fixed number of centers at either endpoint has no effect.

On the shoulders `c1 W<=|R^2-p|<=c2 W/2`, every active odd d has sine of the same sign as `R^2-p`; its magnitude is bounded below by a positive constant on the interior d interval. The small fixed c2 keeps the angle strictly inside `(-pi/2,pi/2)` for both h. By (3.2),

    |G_h(R)| asymp |G_h'(R)| asymp T^(-1/2)             (3.3)

on a subinterval of each shoulder. Their characters have product `chi4(45)=1`, so the product in (3.3) is positive.

There is no hidden negative contribution elsewhere in the covariance. If both localized fibres are nonzero, their centers differ by a multiple of `2g`, by (2.5)'s parity statement. But their distance is at most `2c2 W`, and `W/g -> 0`; hence the centers must coincide. At a common center the characters have positive product and all nonzero sine factors have the same detuning sign. Since every amplitude and tau is nonnegative, `G_h G_h'>=0` over the entire w window.

Each shoulder has R-length comparable to `W/T=N^(-1/2)`, by the exact change of variables `dR=dx/(2sqrt(x))`. Summing the comparable-to-T disjoint shoulders, each with integrand comparable to `T^(-1)`, proves

    integral G_(5g) G_(9g) dmu_T asymp N^(-1/2).       (3.4)

The matching upper bound uses the same spacing count, `|G_h|<<T^(-1/2)`, and the total support measure. The identical argument applied to a single h gives

    integral G_(5g)^2 dmu_T asymp N^(-1/2),
    integral G_(9g)^2 dmu_T asymp N^(-1/2).             (3.5)

Thus for any fixed sigma>0 the putative uniform certificate

    |integral G_h G_h' dmu_T|
      << T^(-sigma)(integral G_h^2 dmu_T
                         integral G_h'^2 dmu_T)^(1/2), h!=h',  (3.6)

is false. All constants in the construction are fixed as T tends to infinity.

The same amplitude with `h=5g,h'=7g` gives `G_h G_h'<=0` everywhere, with covariance `-asymp N^(-1/2)`: common centers are `35gk`, and `chi4(35)=-1`. Both stationary lines again meet the positive support. With `h=5g,h'=6g`, exact common products with odd quotients are impossible. Distinct centers differ by at least g, whereas the localization widths are o(g), so `G_(5g)G_(6g)=0` identically for sufficiently large T. These are three actual arithmetic outcomes, not a hypothesis that every pair has the same correlation sign.

These controls use a subsequence of real T and ordinary real detuned radii, which suffices to refute the uniform statement (3.6). They do not require R itself to be an integer or a complex number. At the exact centers every real leading fibre is zero, as required. The covariance survives on both shoulders because the product of the two odd kernels is even in the common detuning.

### 3.3 Exact product ownership and a bound for one product packet

For a general rectangle, the inherited symbol estimates, including any fixed number of d derivatives, give

    |partial_d^j b_h(d;R)| << A0 D^(-j),
    A0=N^(-3/4)R sqrt(D) H^(-3/2),
    A0 D asymp T^(-1/2).                               (3.7)

Trivially `|S_h|<<A0D`. More strongly, smooth summation on the odd integers gives, for each fixed A,

    |S_h(R)| <<_A T^(-1/2)
                  (1+D|Delta_h|/h)^(-A).               (3.8)

For completeness, apply Poisson summation on the lattice `d=2j+1` to `b_h(d;R)exp(i pi Delta_h d/(2h))`. In the unique cell `|Delta_h|<=h`, its frequency is at distance `|Delta_h|/(4h)` from the closest frequency in `(1/2)Z`. Repeated integration by parts in the smooth compactly supported d symbol bounds the closest Fourier transform by `A0D(1+D|Delta_h|/h)^(-A)`; all other aliases are bounded by its right side after increasing derivative order. Taking the imaginary part proves (3.8). When D is bounded, the trivial bound already implies (3.8), with an A-dependent constant because `D|Delta_h|/h` is bounded. This argument is uniform at the cell boundary and does not assert an exact reflected amplitude.

Group the finite h sum by its actual assigned integer p:

    S(R)=sum_p P_p(R),
    P_p(R)=sum_(h asymp H: p=h q_h(R^2)) S_h(R).       (3.9)

This is an exact regrouping, not an extra summation over all equivalent q labels. In the active range `p asymp T^2`; the elementary divisor bound gives at most `T^epsilon` h for each p. Since `h/D asymp W=T/sqrt(N)`, (3.8) implies

    |P_p(R)| <<_(A,epsilon) T^(-1/2+epsilon)
                   (1+|R^2-p|/W)^(-A).                (3.10)

The estimate permits complete coherence among divisors of p. It also retains exact resonance zeros, although the upper bound does not require them.

Summing (3.10) absolutely gives only

    |S(R)| << T^epsilon [T^(-1/2)W+T^(-1/2)]
            =T^epsilon [(T/N)^(1/2)+T^(-1/2)].         (3.11)

This is the inherited absolute certificate, now with unique product ownership and rapid smooth tails. It is an upper envelope, not an actual lower bound.

For any fixed eta>0 and K>0, choose A sufficiently large. Summing (3.10) over `|R^2-p|>T^eta W` gives `O(T^(-K))`, uniformly in R, because its bound is

    << T^(-1/2+epsilon) W T^(-(A-1)eta)

up to harmless endpoint constants. In the remaining finite set, each packet is at most `T^(-1/2+epsilon)`. Therefore `|S(R)|>V`, after subtracting the negligible error, forces at least

    c_epsilon V T^(1/2-epsilon)                       (3.12)

nonzero packets with the sign of S. This follows by bounding the sum of packets with that sign by their number times (3.10). Constants and a harmless factor 2 are absorbed in c_epsilon. For `V=T^(16/125)`, the power is `157/250=0.628`.

The full band has only logarithmically many smooth divisor rectangles. Its summed stationary error is negligible as recorded below. Thus a large F forces a rectangle above `V` divided by a fixed power of log T, and the same necessary count follows with an epsilon loss for at least one rectangle. This is a necessary condition only: no rarity bound for such configurations has been proved.

At the central scale `N=T^(2/3)`, the natural window contains on the order of `W=T^(2/3)` possible integer centers, more than the required threshold count `T^(157/250)`. Product capacity therefore does not rule out the event. It also does not prove that the event occurs. A coherent same-product packet, whose entire size is at most `T^(-1/2+epsilon)`, is far below this upper-tail threshold.

No correction or far-product tail has been counted as part of a putative signed saving. ## 4. First doubtful or unproved step

All arithmetic and covariance statements above are proved for their stated quantities. The first missing step for target A is a quantitative bound for the measure, or integrated twelfth excess, of radii where the actual signed sum (3.9), assembled over all rectangles, reaches `V>=T^(16/125)` through the many-center contribution in (3.12).

Neither of the following shortcuts supplies it:

* Replacing the covariance of every distinct h pair by a power saving is false by (3.4)--(3.6). Equal 2-adic valuations retain fixed signs at each difference r. Any useful pairwise estimate must separate or pay those classes and prove that the remaining aggregate still saves enough.
* Treating the character signs inside one fixed difference class as equidistributed is false by (2.5). Cancellation between r classes remains possible, but needs estimates for the actual weighted number of solutions and the radius kernels, with their boundaries; an alternating sign in r is not itself a bound for that sum.

The exact product packets and their rapid-decay envelope prove only (3.11). Combining that envelope with the original trivial `N^(1/4)` bound still meets at `N=T^(2/3)` with ceiling `T^(1/6)`, worse than the available actual ceiling. This limits the stated certificate; it gives no lower bound for F.

The controls are not a disproof of A. In particular, even a positive covariance as large as (3.4) involves individual amplitudes `T^(-1/2)`, far below `T^(16/125)`. The construction does not produce one high-level event. The same-product multiplicity bound explains quantitatively why the earlier individual-fibre control cannot on its own decide the upper-tail question.

function chi([int]$n) {

  return -1

function gcd([int]$a,[int]$b) {
  while ($b -ne 0) { $v=$a%$b; $a=$b; $b=$v }
  return $a
}
for ($h=1; $h -le 24; $h++) {

  }
