## Exact result audited

Theorem 1.1 proves, in the paper's normalization,

\[
 P(x)=\Omega_-
 \left((x\log x)^{1/4}
 (\log_2x)^{\frac34(2^{1/3}-1)}\right).
\]

The method inserts a one-sided sectorial Gamma-density kernel into a
resonance argument for the truncated Voronoi phase. The general
trigonometric-polynomial result, Theorem 1.2, is an existence/lower-bound
device over a long real interval; it is not a uniform upper estimate for
a fixed physical packet.

## Project interface audit

This result concerns signed large values and therefore reinforces the
expected \(1/4\) lower barrier, but it gives no upper bound. Its sectorial
kernel selects a favorable evaluation point after averaging over an
interval. The project needs pointwise, fixed-\(X\), coefficient-preserving
upper cancellation on literal M1/M2 packets. Consequently the method does
not estimate the aligned \(P_{\partial\mathrm{lit}}\) face, either M2
owner, endpoint uniformity, or a bridge.
