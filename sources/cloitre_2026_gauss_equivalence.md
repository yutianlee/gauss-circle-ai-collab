# Source Card: Cloitre 2026 Fibonacci/Gauss equivalence

## Bibliographic data

Benoit Cloitre, *Fibonacci, Dirichlet, and Gauss in a single sum*,
arXiv:2607.20960v1 [math.NT], submitted 23 July 2026.

- Abstract record: https://arxiv.org/abs/2607.20960v1
- Primary HTML: https://arxiv.org/html/2607.20960v1

## Exact result audited

Theorem 1.1 expresses the odd-index fractional-part sum as

\[
 \mathcal F(n)=\frac{\pi}{8}n+
 \frac14\left(\Delta_C(n)-\Delta_C(n/2)\right)+O(n^\varepsilon)
\]

for odd \(n\ge3\), and gives a corresponding divisor-error identity for
even \(n\). The paper also derives converse implications for the
associated error exponents.

## Project interface audit

The result transfers the classical discrepancy to a different sequence;
it does not improve the discrepancy itself. It supplies no literal M1 or
M2 coefficient theorem, no endpoint estimate, and no route connector.
